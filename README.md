# SKD concept

Статическая презентация предварительной концепции логистического оператора.
Сценарии, тарифы и критерии пилота требуют дальнейшей проверки и согласования.

Планируемый адрес: https://cerpick-sudo.github.io/skd-concept/

Основная презентация находится в `site/`. Страница о поезде из Уху в Круглое Поле и её PDF находятся в `site/krugloe-pole/`. Контрольные суммы всех публикуемых файлов перечислены в `site-manifest.json`.
Публикация запускается вручную из GitHub Actions, только из ветки `main`
репозитория `cerpick-sudo/skd-concept`. Отправка коммита сама по себе не публикует сайт.

Workflow проверяет интерфейс в Chromium на трёх размерах экрана, синтаксис JS,
локальные ссылки и SHA-256; затем собирает и публикует артефакт.
После размещения скачивает все файлы из манифеста и сравнивает их SHA-256.
Версия, commit SHA, GitHub run ID, run attempt и SHA-256 `artifact.tar`
сохраняются в отчёте GitHub Actions.

Для этого сайта согласована схема GitHub-hosted runner `ubuntu-24.04`
и GitHub Pages. Она не использует SSH, отдельный сервер, root-owned wrapper
или Build Center. Дополнительные постоянные секреты не требуются.

Для отката следует восстановить предыдущую проверенную версию и её manifest
в `main`, затем вручную повторить тот же workflow. История предыдущих выпусков
появится только после первой успешной публикации.
